# SaveMe

**SaveMe** — Unity-проєкт, який поєднує ігрову логіку на **C#** з візуальними ефектами, створеними за допомогою **ShaderLab** та **HLSL**.

Проєкт розроблений як атмосферна 3D/2D гра або ігровий прототип, де увага приділяється не лише механікам, а й візуальній подачі та ефектам рендерингу.

## Основні можливості

- логіка гри на **C#**;
- кастомні шейдери на **ShaderLab** / **HLSL**;
- робота з Unity-ассетами, матеріалами та префабами;
- гнучка структура для розширення ігрових механік;
- підтримка візуальних ефектів, що покращують атмосферу проєкту.

## Технології

- **Unity**
- **C#**
- **ShaderLab**
- **HLSL**

## Структура проєкту

Типова структура Unity-проєкту включає:
- `Assets/` — скрипти, сцени, префаби, матеріали та ресурси;
- `ProjectSettings/` — налаштування проєкту;
- `Packages/` — залежності та пакети Unity.

## Як запустити

1. Склонуй репозиторій:
   ```bash
   git clone https://github.com/TrutRoman/SaveMe.git
   ```

2. Відкрий проєкт через **Unity Hub**.

3. Дочекайся завершення імпорту ассетів і шейдерів.

4. Відкрий потрібну сцену та натисни **Play** в Unity Editor.
